# UP Service

উপজেলার নাগরিক সেবাগুলো সহজে খুঁজে পাওয়ার জন্য একটি responsive বাংলা ওয়েব অ্যাপের প্রাথমিক সংস্করণ।

## চালু করুন

প্রথমে dependencies ইনস্টল করুন:

```bash
npm install
```

তারপর লোকাল সার্ভার চালান:

```bash
npm start
```

`http://localhost:8000` খুলুন। চাইলে `index.html` ফাইলটি সরাসরি ব্রাউজারেও খোলা যাবে।

## এই সংস্করণে

- নাগরিক, ভূমি, সামাজিক ও অন্যান্য সেবার তালিকা
- সেবার নাম দিয়ে খোঁজা এবং বিভাগ অনুযায়ী ফিল্টার
- সেবার বিস্তারিত, প্রয়োজনীয় কাগজপত্র ও যোগাযোগের তথ্য
- মোবাইল ও ডেস্কটপ উপযোগী নকশা

এটি একটি প্রাথমিক frontend prototype। এখানে কোনো বাস্তব আবেদন জমা, ব্যক্তিগত তথ্য সংরক্ষণ বা সরকারি সিস্টেমের সঙ্গে সংযোগ নেই।
